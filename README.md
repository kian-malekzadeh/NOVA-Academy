## دربارهٔ پروژه

**نُوا آکادمی (NOVA Academy)** یک وب‌سایت تک‌صفحه‌ای و کاملاً فارسی (RTL) برای آموزشگاه زبان انگلیسی است. این صفحه با هدف معرفی حرفه‌ای و شادِ دوره‌ها، روش برگزاری کلاس‌ها و راه‌های ارتباط با آموزشگاه طراحی شده است؛ از کودکان تا بزرگ‌سالان (۷ تا ۷۰ سال)، آنلاین در سراسر کشور و حضوری در **تبریز و سلماس**.

محتوای صفحه مستقیماً از سند محتوایی برند استخراج شده و هیچ آمار، نظر یا اطلاعات ساختگی در آن درج نشده است.

## ✨ امکانات

- **کاملاً فارسی و راست‌به‌چپ (RTL)** با اعداد فارسی
- **سیستم طراحی Claymorphism** — کارت‌های سه‌بعدی نرم با حاشیهٔ ضخیم و سایهٔ دوتایی
- **بدون هیچ وابستگی** — فقط HTML + CSS + SVG خالص؛ بدون فریم‌ورک، بدون بیلد، بدون کتابخانهٔ جاوااسکریپت
- **آیکون‌های SVG خالص** (بدون ایموجی) شامل گلیف‌های دقیق برند **تلگرام** و **واتس‌اپ**
- **طراحی واکنش‌گرا (Responsive)** — موبایل، تبلت و دسکتاپ
- **دسترس‌پذیری** — کنتراست ۴.۵:۱، حلقهٔ فوکوس، aria-label، لینک پرش، پشتیبانی از `prefers-reduced-motion`
- **انیمیشن‌های ورود نرم** با پشتیبانی از حالت بدون-انیمیشن
- **داده‌های ساخت‌یافته (JSON-LD)** برای موتورهای جستجو
- **دکمه‌های تماس، تلگرام و واتس‌اپ** در سراسر صفحه (هدر، هیرو، بنر، فوتر و دکمهٔ شناور)

پروژه هیچ مرحلهٔ build ندارد؛ صفحه کاملاً مستقل است:
